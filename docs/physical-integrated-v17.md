# v17 integrated physical mechanics (experimental)
Separate branch. Prior paths preserved by graph version flags. New graphs opt into integrated mechanics.
Solid sliding contacts: explicit normal load N, static coefficient from friction/roughness, kinetic/static ratio and recovery time. A static velocity constraint applies equal/opposite impulse if within static limit; otherwise a capped kinetic impulse weakens contact state with sliding distance and permits recovery on sticking. Impulse work is dissipative and recorded. Up to 32 filament modes below the sample-rate limit resolve sharper spatial motion; other objects retain seven modes. This is a reduced friction curve/history model, not measured thermal rosin or full spatial contact.
Fluid valve: free transfer fluid, flexible solid and confined fluid object. Nonzero rest gap enables pressure-controlled opening (signed polarity); flexible object's first cantilever mode derived from geometry and E/rho. Bernoulli flow through changing gap, Reynolds-dependent discharge, mean through-flow removal, modal volume compression. All positive pressure/volume work is charged to kinetic energy, seat collision loss and exhaust tracked. No pitch oscillator. Single flexible element only; double reeds, lips, free reeds, full 3D flow/turbulence are not validated. Valve mode uses one beam bending coordinate and a reduced pressure-port basis, not a full fluid-structure solver. The edge model remains available and unchanged. 
STRING button alternates guitar/violin construction; WIND alternates jet and flexible-valve construction. New controls only appear on relevant links. All examples use editable physical fields, not hidden instrument synthesis.
Tests export WAV and physical CSV, measure stick/slip transitions, pressure/flow/gap, energy and rendered pitch; test zero source/friction/engagement and sample rates. Numerical conservation does not certify timbre, phase/register accuracy or device polyphony. Sources: https://euphonics.org/9-2-1-time-domain-simulation-of-a-bowed-string/ and https://euphonics.org/11-3-1-modelling-the-clarinet-mouthpiece/.
