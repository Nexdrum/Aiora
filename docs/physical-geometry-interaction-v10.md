# Geometry and interaction v10 prototype

Isolated from APT v9 and native-android. Live scaled schematic depicts axial length, width, depth, curvature, taper and four profile stations, with gas section wall/opening and interaction angle/engagement. Existing sliders edit the same physical fields. This is not a true mesh or direct manipulation editor. New normalized friction, elastic response, restitution, area, clearance, adhesion and solid contact mix controls modify the reduced contact solver. Existing laws remain as starting regimes; mix blends normal and tangential contact for solids, not flow. Neutral defaults retain v9 behavior. Values are empirical normalized coefficients, not calibrated SI measurements. Calibration stamp includes new fields. Sustain Reset deferred. Android package suffix .geometryv10.
