# v18 acoustic scan and keyboard calibration
Isolated experiment from v17. The physical solver is unchanged. SI Scan All enumerates every currently supported object property whose isolated model responds by >80 cents; candidates with >=2 modeled keys are retained rather than top-three preselection/top-eight output. Model-only or reference-unverified candidates are visible but cannot be applied. The old path is retained for pre-SI graphs. The SI path searches single properties, not combinations; manual Find retains the older model-based solve. Link-only and newer material/geometry controls without an isolated-frequency response are not yet acoustically searched.
The isolated solution is only a starting point. Each candidate with a viable anchor is refined using actual 48 kHz output, 24576 recorded samples and a zero-padded 65536-point FFT without decimation aliasing. Select real spectral peaks near the target and the modeled mode, allow a weak but locally distinct peak (>1.5% strongest and >1.6x nearby skirts), penalize weak evidence in ranking. Iteratively correct the model target using rendered cents error, bounded to 600 cents. Confirm movement relative to neighboring verified notes; reject stationary/reversed branches. Use a consistent middle-C anchor when available, with a reference fallback. Every marked playable integer key has a measured peak within 10 cents; holes remain unverified. Only candidates with a verified reference and >=2 verified keys can apply. The full 128-note model map is considered; actual analysis is bounded to 25–3500 Hz and within three semitones of modeled reach. Not a psychoacoustic pitch detector: a valid but weaker moving peak may coexist with a louder body resonance. Some ranges or references fail.
Apply uses the corrected physical values. The B table interpolates corrected neighboring integer values in their native physical property space at 1/8 semitone; it does not re-solve isolated frequencies or pitch-shift audio. No interpolation across unverified integer holes. Existing nearest-valid fallback remains at holes/outside range. Nine fractional positions are independently rendered in the regression; not all substeps are acoustically verified. The fine-map key includes corrected integer values/playability so stale acoustic maps are rejected. Scan stays on the existing worker, no solver/FFT in audio render. 
Tests: full integrated acoustic guitar graph at reference MIDI 60 and 50, rank string length, independently re-render every verified key, check monotonic length, sampled fractional B accuracy, live B updates actual geometry and energy balance, stale map invalidation. No claims of accuracy for every instrument or varying V/M, Android scan latency or device performance.
